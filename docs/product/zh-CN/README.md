# 产品文档（中文）

本目录面向「把产品做成能交付、能运营、能持续迭代」的目标，提供从产品定位到接口、部署、隐私安全、验收清单的一套闭环文档。

## 文档导航

- `docs/product/zh-CN/00-产品总览.md`：产品定位、用户、场景、指标、范围与术语
- `docs/product/zh-CN/01-用户指南.md`：面向使用者（患者/运营/医生助理）的操作说明与常见问题
- `docs/product/zh-CN/02-部署与运维.md`：本地/容器化部署、环境变量、排障、观测
- `docs/product/zh-CN/03-API参考.md`：后端 API 说明（含 SSE 流式匹配）
- `docs/product/zh-CN/04-隐私与安全.md`：PHI/合规策略、数据最小化、日志与留存建议
- `docs/product/zh-CN/05-验收清单.md`：上线前验收与回归 checklist
- `docs/product/zh-CN/06-目标架构与演进.md`：CTO/CMO 目标架构、非功能指标、演进路线
- `docs/product/zh-CN/07-医学内容与安全治理.md`：最小医学数据集、试验/规则治理、安全护栏与评估

## 建议阅读顺序

1. `00-产品总览.md`
