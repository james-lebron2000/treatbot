# 验收清单（上线/演示前）

## 1. 功能回归（主链路）

- 注册成功后自动登录，刷新页面仍保持登录状态
- 登录失败提示明确（密码错误/账号锁定/频控）
- 创建患者成功，患者列表可见
- 上传病历成功，能看到 OCR/解析结果
- 匹配任务能启动，结果页能持续收到 SSE 更新
- 结果可筛选/保存，历史页可回看/恢复

## 2. 数据与边界条件

- 上传空文件/不支持格式：有明确错误提示
- 文本缺失关键字段：系统提示“待确认项”，不会崩溃
- 试验数据为空：提示“暂无试验数据/请先初始化”

## 3. 性能与稳定性（最低要求）

- `/api/health` 在 2 秒内响应
- 匹配任务可在可接受时间内完成（Demo 可用批处理模拟）
- SSE 断线后刷新页面可恢复查看状态（至少可通过 status 查询）

## 4. 安全与合规（最低要求）

- 未登录访问业务接口返回 401/403
- 日志不包含 token、密码、完整病历原文
- `LLM_PHI_MODE` 为 `disallow` 时不会触发任何外部 LLM 调用
