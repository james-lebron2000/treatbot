## 📈 成本优化建议

### 优先级1: 分批处理（推荐）✅

**问题**: 一次性处理所有试验消耗大量Token

**解决方案**: 两阶段匹配
```javascript
// 阶段1: 快速预筛选（无LLM）
const candidates = classicMatch(allTrials, patientData);
// 筛选出前50-100个候选

// 阶段2: LLM精确匹配
const finalMatches = await llmMatch(candidates, patientData);
```

**节省**: 如果从1000个筛选到100个，节省 **90% Token成本**

---

### 优先级2: 缓存机制 ✅

**已实现**: 
- Match History存储
- 重复匹配直接返回历史结果

**节省**: 相同患者重复匹配 **100% Token成本**

---

### 优先级3: CSV优化

**当前问题**: CSV包含大量冗余字段

**优化方案**:
```csv
# 精简版CSV (只保留关键匹配字段)
trial_id,condition,age_min,age_max,gender,mutations
NCT001,肝癌,18,70,both,KRAS
```

**节省**: 约 **30-40% 输入Token**

---

### 优先级4: 向量检索（高级）

**方案**: 使用Embedding预筛选
```javascript
// 1. 为所有试验生成Embedding（一次性）
const trialEmbeddings = await generateEmbeddings(allTrials);

// 2. 快速向量相似度检索
const topK = vectorSearch(patientEmbedding, trialEmbeddings, k=50);

// 3. LLM精确匹配前50个
const matches = await llmMatch(topK, patientData);
```

**节省**: 95%+ Token成本（对于大规模数据）
