- `hybridMatchingService.js` (341 lines)
- `matchEngineService.js` (393 lines)

**Severity**: 🔴 **Critical**

#### Problem Analysis

```javascript
// ❌ 现状：4个服务，功能重叠
trialMatchingEngine      // 规则引擎 + 批处理
enhancedTrialMatcher     // 增强规则引擎（与上面重叠）
hybridMatchingService    // 混合模式（粗糙+LLM）
matchEngineService       // 辅助工具（应该是 utils）

// ✅ 优化后：统一 Facade + Strategy 模式
TrialMatchingFacade (统一入口)
├── strategies/
│   ├── RuleBasedMatchStrategy.js       // 整合 engine + enhanced
│   ├── HybridMatchStrategy.js          // 保留 hybrid
│   └── LLMEnhancedMatchStrategy.js     // LLM 增强
└── utils/
    └── matchEngineHelpers.js           // matchEngineService 改为工具
```

#### Refactoring Strategy

1. **创建统一 Facade**
   ```javascript
   class TrialMatchingFacade {
     constructor(strategy) {
       this.strategy = strategy;
     }

     async match(patientData, trials, options) {
       return this.strategy.execute(patientData, trials, options);
     }
   }
   ```

2. **使用 Strategy 模式**
   ```javascript
   // 使用示例
   const facade = new TrialMatchingFacade(
     new HybridMatchStrategy()
   );
   const results = await facade.match(patientData, trials);
   ```

### **Issue #3: Broken Dependency Injection**

**File**: `server/controllers/medicalController.js` (lines 38-41)
**Severity**: 🔴 **Critical**

#### Bad Code

```javascript
// ❌ 控制器直接实例化服务（违反 DI 原则）
const ocrService = new AlibabaOCRService();
const llmService = new LLMIntegrationService();
const stepwiseLLMService = new StepwiseLLMService();
const trialMatchService = new TrialMatchingService();
```

#### Good Code (Using ServiceContainer)

```javascript
// ✅ 使用 DI Container
const { defaultContainer } = require('../services/ServiceContainer');

const ocrService = defaultContainer.deps.ocrService;
const llmService = defaultContainer.deps.llmService;
const stepwiseLLMService = defaultContainer.deps.stepwiseLLMService;
const trialMatchService = defaultContainer.deps.trialMatchService;
```

#### Why This Matters

| Direct Instantiation | Dependency Injection |
|---------------------|---------------------|
| ❌ Hard to test (cannot mock) | ✅ Easy to test (inject mocks) |
| ❌ Tight coupling | ✅ Loose coupling |
| ❌ Cannot swap implementations | ✅ Can swap at runtime |
| ❌ Duplicate instances | ✅ Singleton management |

### **Issue #4: Data Clump (Parameter Pollution)**

**Files**: Multiple controllers and services
**Severity**: 🟡 **Medium**

#### Problem

```javascript
// ❌ 数据泥团：相同参数反复出现
async function matchTrials(structuredData, patientId, recordId, userId, options) {
  // ...
}

async function enhancedMatch(structuredData, patientId, recordId, userId, jobId, useHybrid) {
  // ...
}
```

#### Solution: DTO Pattern

```javascript
// ✅ 使用 DTO (Data Transfer Object)
class MatchRequest {
  constructor({ structuredData, patientId, recordId, userId, options }) {
    Object.assign(this, { structuredData, patientId, recordId, userId, options });
  }

  validate() {
    if (!this.structuredData) throw new Error('structuredData is required');
    // ...
  }
}

// 使用示例
async function matchTrials(request) {
  request.validate();
  const { structuredData, patientId, userId } = request;
  // ...
}
```
